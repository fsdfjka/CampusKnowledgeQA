# 校园知识库问答系统 · 项目说明

基于 **RAG（检索增强生成）** 的校园智能问答系统，包含学生前台问答、管理后台、知识库管理、混合检索、多轮对话与流式输出。

---

## 1. 技术栈

| 层 | 技术 |
|---|---|
| 后端 | Spring Boot 4.1.1、Java 17 |
| AI 框架 | Spring AI 2.0.0-M1、Spring AI Alibaba（DashScope）2.0.0-M1.1 |
| 大模型 | 阿里云百炼 DashScope（对话 `qwen-turbo`，向量 `qwen3.7-text-embedding`） |
| 向量库 | PostgreSQL 17 + pgvector 0.8.6 |
| 文档解析 | PDFBox 3（PDF/表格）、Apache POI 5.4.1（Word） |
| 前端 | Vue 3.6(rc) + Vite 8 + Pinia + Vue Router 5 + Element Plus + ECharts |
| 构建 | Maven 3.9、Node 24 |

## 3. 环境搭建

### 3.1 数据库（PostgreSQL 17 + pgvector）

- 安装位置：`D:\PostgreSQL\17`，数据目录 `D:\PostgreSQL\data17`
- 服务：`postgresql-x64-17`（自动启动，端口 5432）
- 账号：`postgres` / `postgres`
- 数据库：`campus_kb`
- pgvector：将 `vector.dll` 放入 `D:\PostgreSQL\17\lib`，扩展文件放入 `share\extension`，执行 `CREATE EXTENSION vector;`

```sql
CREATE DATABASE campus_kb;
\c campus_kb
CREATE EXTENSION IF NOT EXISTS vector;
```

### 3.2 后端配置（`application.yml`）

```yaml
server:
  port: 8081

app:
  rag:
    chunk-size: 600          # 文本切片大小（token）

spring:
  autoconfigure:
    exclude:
      - org.springframework.ai.vectorstore.pgvector.autoconfigure.PgVectorStoreAutoConfiguration
  datasource:
    url: jdbc:postgresql://localhost:5432/campus_kb
    username: postgres
    password: ${POSTGRES_PASSWORD:postgres}
  ai:
    dashscope:
      api-key: ${DASHSCOPE_API_KEY}
      chat:
        options:
          model: qwen-turbo
      embedding:
        options:
          model: qwen3.7-text-embedding
          dimensions: 1024
```

> `application.yml` 已被 `.gitignore` 忽略，仓库里只保留 `application.example.yml`。

## 4. 后端核心设计

### 4.1 依赖版本对齐（重要踩坑）

| 问题 | 现象 | 解决 |
|---|---|---|
| `spring-ai-bom` 版本 | 用 2.0.1 与 alibaba M1.1 不匹配，缺 `ToolExecutionEligibilityPredicate` | BOM 降为 **2.0.0-M1**，与 alibaba `2.0.0-M1.1` 对齐 |
| DeepSeek 坐标 | `spring-ai-deepseek-spring-boot-starter` 不存在 | 改为 `spring-ai-starter-model-deepseek`（后移除，仅用百炼） |
| 百炼包缺类 | `DashScopeMultimodalEmbeddingAutoConfiguration` 在 jar 中缺失 | 排除该自动配置 / 补空实现 |
| pgvector Bean 冲突 | 自动配置与自定义 `vectorStore` 重名 | 排除 `PgVectorStoreAutoConfiguration` |

### 4.2 向量库（`KnowledgeVectorStore` + `AiConfig`）

- 手动构建 `PgVectorStore`（1024 维、COSINE、HNSW、`initializeSchema=true`），并手动调用 `afterPropertiesSet()` 建表；
- 维度从配置读取：`spring.ai.dashscope.embedding.options.dimensions`；
- 封装 `clear()`（TRUNCATE）与 `getAllDocuments()`（查表）供文档列表/关键词检索使用。

### 4.3 混合检索（`HybridRetriever`）

- **向量检索**：`similaritySearch`（不设阈值，取候选）；
- **关键词检索**：中文 2-gram / 英文词，按词频×词长打分；
- **RRF 融合**：`score = Σ 1/(60 + rank)`，取 Top-K。

### 4.4 多轮对话（`ChatController` + `QueryRewriter`）

- 请求体 `{ question, history }`，服务端组装 `System(含RAG上下文) + 历史 + 当前问题`；
- **查询改写（指代消解）**：结合历史把追问改写成独立检索问题（如「那它周末开吗」→「图书馆周末开放吗」），失败则回退为拼接；
- 历史截断：最多保留最近 5 轮，避免 token 膨胀；
- 空检索兜底：「（无相关知识库内容）」。

### 4.5 流式输出（SSE）

- `POST /chat/stream`，`produces=text/event-stream`，返回 `Flux<String>`；
- 逐块推送，出错时通过 `onErrorResume` 发回错误事件。

### 4.6 文档解析

| 类型 | 解析方式 | 表格处理 |
|---|---|---|
| PDF | `PagePdfDocumentReader` + `PdfTableExtractor`（PDFBox 3 坐标聚类） | 转 Markdown |
| Word(.docx) | POI `XWPFDocument`（段落 + 表格） | 转 Markdown |
| Word(.doc) | POI `HWPFDocument` 纯文本 | 不支持结构化 |
| TXT/MD | 直接读文本 | — |

### 4.7 大文档 / 超 token 防护（`DocumentLoadService`）

按「单条文档不超 embedding 上限（8191×0.9≈7371 token）」设计：

1. **文本切片**：`TokenTextSplitter`，chunkSize 可配（默认 600）；
2. **表格分块**：按行（≤30 行）且按字符（≤1500）分块，**每块重复表头**；
3. **最终兜底**：任何单条 >1500 字符则按字符硬切（带 100 字符重叠），确保不超 token；
4. **分批入库**：每 50 片一批 `add`，单批失败重试 2 次（退避）。

### 4.8 接口清单

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/chat?question=` | 单轮问答（Result 包装） |
| POST | `/chat/stream` | 多轮流式问答（SSE，body: `{question, history}`） |
| POST | `/uploadDocument` | 统一文件上传入库（按扩展名分流 pdf/docx/doc/txt/md） |
| POST | `/loadText` | 纯文本入库（JSON body） |
| GET | `/documents` | 查询已入库文档（按 source 汇总） |
| DELETE | `/clearVector` | 清空向量库 |

### 4.9 安全

- `DocumentController` 文件路径统一限制在 `uploads/` 目录内（`normalize` + `startsWith` 校验），防止**路径遍历**；
- 上传文件名做 basename 清洗，防 `../` 逃逸。

## 5. 前端

### 5.1 统一登录（`/login`）

按账号密码校验角色并分流：

| 角色 | 账号 | 密码 | 入口 |
|---|---|---|---|
| 学生 | `student` | `123456` | `/student/chat` |
| 管理员 | `admin` | `admin123` | `/dashboard` |
| 超级管理员 | `superadmin` | `super123` | `/dashboard` |

- 学生可注册（仅学生角色显示注册入口）；
- 守卫按 `stu_token` / `ck_token` 分区鉴权，非法/过期会话自动清理，避免重定向死循环。

### 5.2 学生前台（`/student`）

- 智能问答（复用真实 `/chat/stream`，流式 + 引用来源 + 点赞/点踩/反馈 + 敏感词拦截）
- 知识库浏览（分类 + 搜索 + 详情）
- 历史记录 / 收藏
- 热门问题
- 个人中心（资料 + 改密）

### 5.3 管理后台（`/dashboard`）

- 工作台、知识库（文档/分类）、问答记录、数据统计
- **管理员**：反馈管理、敏感词管理
- **超级管理员**：用户管理、角色权限、日志与备份、系统配置

菜单与路由按角色过滤（`meta.roles` + RBAC）。

## 8. 已知限制与后续优化

1. **异步入库**：大文档解析+向量化耗时长，建议改为「上传返回任务 id + 后台处理 + 状态轮询」（表已预留 `kb_document.status`）。
2. **上传大小**：Spring 默认 1MB，需配置 `spring.servlet.multipart.max-file-size`。
3. **表格/扫描件**：复杂合并单元格、扫描件效果有限，可引入多模态模型（qwen-vl）整页转 Markdown。
4. **前端数据**：学生端与管理端部分数据仍为 Mock（`src/mock/*`），需接后端接口。
5. **鉴权**：目前为前端假登录，生产需接入真实 JWT/会话与后端校验。
6. **密钥安全**：`DASHSCOPE_API_KEY`、数据库密码请使用环境变量，勿提交仓库。

## 9. 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| `package com exists in another module` | 根包不要用单段 `com`，统一 `com.campusknowledgeqa` |
| `ToolExecutionEligibilityPredicate not present` | Spring AI BOM 与 alibaba 版本不一致，用 2.0.0-M1 |
| `Unable to read meta-data for ...DashScopeMultimodalEmbeddingAutoConfiguration` | 百炼 M1.1 jar 缺类，排除该自动配置 |
| `single document exceeds max input tokens` | 切片 + 表格分块 + 1500 字符硬切兜底 |
| `vector_store` 表不存在 | 手动构建的 `PgVectorStore` 需调用 `afterPropertiesSet()` |
| 端口 8081/5173 被占用 | 多为残留进程，`Get-NetTCPConnection -LocalPort <port>` 后 `Stop-Process` |
| 换 embedding 模型后检索不准 | 旧向量不可比，需清空 `vector_store` 并重新入库 |
